# Генератор случайных чисел от 1 до N-1

Программа генерирует массив случайных чисел диапазона 1..N-1 с указанной стратегией. Для генерации необходимо ввести два целых числа.

- Первое число (N): диапазон генерации от 1 до N-1 (исключаем 0)
- Второе число (M): сколько уникальных чисел сгенерировать
- Проверка: при коллизии генерируем новое число
- Валидация: только целые положительные числа, без букв и спецсимволов
- Выход: массив в формате [ 1, 23, 4, 17 ]

## Принцип работы
Автоматически выбирает стратегию на основе соотношения M/N:

> ### Если M < N/2 → используем HashSet (Экономит память при малых M)

> **Принцип:**

> Используем HashSet для хранения уникальных чисел
> Генерируем числа через rand::Rng
> При коллизии просто повторяем генерацию
> Простой, надежный, подходит для 80% случаев

> **Плюсы:**

> O(1) проверка на уникальность
> Простая реализация
> Эффективен при M << N (когда генерируем мало чисел из большого диапазона)

> **Минусы:**

> При M близком к N (например, нужно сгенерировать 900 из 1000) будет много коллизий,  производительность падает

<br>

> ### Если M >= N/2 → используем алгоритм перемешивания Fisher-Yates (Гарантирует производительность при больших M) 

> **Принцип:**

> Создаем вектор всех возможных чисел от 1 до N-1
> Перемешиваем с помощью rand::seq::SliceRandom
> Берем первые M элементов

> **Плюсы:**

> Гарантированное время выполнения (предсказуемо)
> Нет коллизий вообще
> Идеально при M близком к N

> **Минусы:**

> Требует O(N) памяти (может быть проблемой при N > 10_000_000)
> Нужно создавать полный диапазон чисел

<br>
    
Добавляем проверку на валидность: если M > N-1, сообщаем об ошибке
